# Source packs

The original art and sound packs the build tools read from. Everything here is by Kenney (kenney.nl), CC0 (public domain).

| Folder / file | What | Used by |
|---|---|---|
| `kenney-audio/` | Casino, Impact, Interface, Music Jingles and RPG audio packs (unzipped) | `tools/game-sfx.mjs`, `tools/plinko-sfx.mjs` |
| `kenney_food-kit.zip`, `kenney_nature-kit.zip` | the Food and Nature 3D kits as downloaded | unzip next to them to use |

Downloaded art (Fluent Emoji, OpenMoji) and the tools' working files are kept in `tools/.cache/`; the one-off test scripts
used while building Sparkle Match and Puzzle Shelf are in `tools/dev/`.
